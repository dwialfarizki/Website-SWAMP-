# SWAMP (v2.4) — Scoped Web Assessment & Management Platform

**SWAMP** adalah platform asesmen keamanan aplikasi web terpadu yang dirancang untuk mendukung proses *vulnerability assessment*, verifikasi temuan secara manual (*Authoring Workspace*), pengujian ulang (*Retesting Comparison*), serta penegakan cakupan target secara ketat (*Scope Protection*).

Platform ini mengacu pada standar pengujian **OWASP Web Security Testing Guide (WSTG v4.2)** dan **Direktif HTTP RFC 9110**.

## Tech Stack

* **Backend**: Python 3.10+, FastAPI, SQLAlchemy ORM, SQLite, Requests/Urllib3, Nmap CLI, cURL.
* **Frontend**: React.js (Vite), Tailwind CSS, Material Symbols Icons.
* **Environment**: Kali Linux / Ubuntu (WSL2) & Windows.
